
> 钱多多见我还是没有听懂，又补充说道："比如，大盘走势向下，意图是补缺口的时候，当刚补完缺口的瞬间，一定会出现几只涨停股票，这个就是同盘共振，这就是一块拼图。比如，大盘低迷，板块轮动时，次新股一定会有所表现，因为不能让打新的人失去信心，这也是一块拼图。比如，龙头上升乏力，而板块没有结束时，一定会有卡位龙的出现，这也是一块拼图。比如，市场在混沌期的时候，已经垂死的老龙，一定会有一波回光返照，这还是一块拼图。你每天辛苦的复盘，不是为了预判未来，应该是在未来出现的时候，你能更快的做出动作，而动作的准确是来自复盘给你带来的经验，是经验化作的一块块拼图。如果你每天想的就是盘面上已经发生的那些事，那这个复盘，对你毫无用处。"

### 复盘不是看热闹

大多数人的复盘是这样的：打开软件，翻一翻涨跌幅榜，看看龙虎榜谁进了谁出了，感慨一句"哎呀这个票我昨天就看好"——然后关掉软件，什么也没留下。

钱多多说的复盘，完全不是这个意思。

复盘的真正目的：**把盘面上正在发生的事情，和自己脑子里已经有的拼图，去做匹配**。对上号了，你就知道接下来大概率会发生什么，就能比别人先一步出手。

### 四块拼图详解

#### 拼图一：补缺口 + 同盘共振

```
场景：大盘连续下跌，正在向下补缺口
信号：缺口回补完成的当天，盘中突然出现几只涨停
↓
拼图匹配：缺口回补 + 涨停共振 = 空方力量衰竭，多头反攻
动作：这是抄底信号，可以进场
```

> 缺口回补是多空双方的一次"结算"，结算完的那一瞬间，最敏感的游资会率先点火。你不需要提前猜缺口什么时候补，但补上的那一刻，你要认得出这个信号。

#### 拼图二：低迷市 + 次新股异动

```
场景：大盘低迷，板块没有主线，资金无处可去
信号：次新股突然集体拉升
↓
拼图匹配：主线缺失 + 次新异动 = 市场需要维持打新信心
动作：短线跟进次新股，快进快出
```

> 市场的水龙头不能关——如果新股上市就破发，打新资金就会撤离，整个融资链条会出问题。所以在行情极度冷清的时候，总会有一股力量去维持次新的热度。这不是阴谋论，这是市场生态。

#### 拼图三：龙头乏力 + 卡位龙

```
场景：板块龙头涨不动了，高位横盘或滞涨
信号：板块内出现一只新票突然放量涨停
↓
拼图匹配：龙头滞涨 + 新票涨停 = 卡位龙接力
动作：切换仓位到卡位龙
```

> 龙头不可能永远涨，资金也不会等龙头死了再找下一个。聪明钱会在龙头还没死透的时候，就去扶下一个。你要做的就是认出谁在接棒。

#### 拼图四：混沌期 + 老龙回光返照

```
场景：市场没有明确方向，新旧热点断档
信号：前期已经回调很久的龙头突然涨停
↓
拼图匹配：混沌期 + 老龙涨停 = 资金无处可去的记忆炒作
动作：小仓位博弈，不要恋战
```

> 老龙是市场共同的记忆。当游资不知道炒什么的时候，就炒老龙——反正大家都认识，不需要做科普。但这种行情通常只有一两天，是资金在等新方向时的过渡行为。

### 怎么培养自己的拼图库

| 步骤 | 具体做法 |
|------|---------|
| **记录** | 每天复盘时，不只记录涨跌，要记录"在什么背景下发生了什么" |
| **归类** | 把相似的市场情境归类——补缺、突破、龙回头、次新异动…… |
| **验证** | 下次再遇到类似情境，验证上次的结论是否成立 |
| **迭代** | 不成立的，修正；成立的，强化——你的拼图会越来越准 |

### 钱多多的忠告

> "复盘不是看历史书，是画地图。你每经历一个场景，就在脑子里画一条路。路多了，地图就完整了。下次再来到这个地方，你不用想，脚下自然就知道往哪走。"
