### 国哥疑惑：怎么做到顺势？

如果不是事后诸葛亮的话，我怎么在局中判断这是什么趋势？

### 趋势的本质

趋势不是"预测出来的"，而是"走出来的"。你不需要猜它往哪走，你只需要等它告诉你它已经往哪走了，然后跟上。

趋势有三个特征：
1. **持续性** — 不是一两天的波动，而是一段连续的方向
2. **方向性** — 高点不断抬高（上升趋势）或低点不断降低（下降趋势）
3. **可跟随性** — 趋势一旦形成，不会立刻反转，有足够的窗口让你上车

### 判断趋势的三个实用方法

#### 方法一：均线排列法

| 趋势类型 | 均线排列 | 含义 |
|---------|---------|------|
| 上升趋势 | 5日线 > 10日线 > 20日线 > 60日线 | 多头排列，短期成本高于长期，资金持续流入 |
| 下降趋势 | 5日线 < 10日线 < 20日线 < 60日线 | 空头排列，短期成本低于长期，资金持续流出 |
| 震荡趋势 | 均线互相缠绕、交叉 | 没有方向，多看少动 |

**操作要点**：只看排列，不猜拐点。均线从缠绕变成多头排列时入场，从多头排列变成缠绕时离场。

#### 方法二：高低点结构法

这是最朴素也最可靠的方法：

- **上升趋势**：每一个高点比前一个高点高，每一个低点也比前一个低点高
- **下降趋势**：每一个高点比前一个高点低，每一个低点也比前一个低点低
- **趋势反转信号**：上升趋势中，出现一个低点低于前一个低点 → 警惕

```
上升趋势结构：
  高点3 ↗
        \
  高点2 ↗ 低点3（高于低点2）
        \
  高点1 ↗ 低点2（高于低点1）
        \
        低点1
```

**操作要点**：在上升趋势中，每次回踩到前低附近而不跌破时，是入场时机。跌破了，趋势可能结束，该走就走。

#### 方法三：成交量验证法

趋势需要成交量来验证：

| 场景 | 量价关系 | 信号 |
|------|---------|------|
| 上涨 + 放量 | 量价齐升 | 趋势健康，持续看多 |
| 上涨 + 缩量 | 量价背离 | 上涨乏力，警惕回调 |
| 下跌 + 缩量 | 缩量下跌 | 抛压减轻，可能见底 |
| 下跌 + 放量 | 放量下跌 | 恐慌出逃，远离 |

### 顺势而为的操作纪律

1. **不抄底、不逃顶** — 你永远不知道底在哪、顶在哪，等趋势走出来再说
2. **右侧交易** — 看到趋势确认了再动手，宁可少赚一段，不要抄在半山腰
3. **趋势在，人在；趋势破，人走** — 不要对股票产生感情，它只是一张纸
4. **震荡市不做方向性判断** — 均线缠绕、方向不明时，空仓就是最好的操作
