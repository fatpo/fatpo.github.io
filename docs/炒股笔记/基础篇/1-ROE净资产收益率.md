
> 巴菲特说：如果这个世界上只能看一个指标，就看 ROE。

### 公式
```
ROE = 净利润 ÷ 公司净资产
```

### 直白意思
股东投进去的本金，一年能赚回多少回报率。**ROE 15% = 每 100 块家底，一年净赚 15 块。**

### 通用合格标准

| ROE | 评级 | 说明 |
|-----|------|------|
| ＜10% | 一般偏弱 | 赚钱效率低 |
| 10%~15% | 稳健合格 | |
| ＞15% | 优秀优质 | |
| ＞20% | 顶尖 | 赚钱能力极强 |

### 银行股 ROE 现状
国有大行 ROE 大多 **10% 左右**，属于稳赚、不暴利、抗跌、分红靠谱的类型，典型烟蒂稳健资产。

### 为啥巴菲特只认它
1. 直接看出真实赚钱本事，造假难度远小于利润
2. 长期高 ROE = 企业护城河深、竞争力强
3. 决定企业能不能持续分红、复利增长
4. 避开虚高营收、账面好看实际不赚钱的公司

### 简单用法
- 连续 **5~10 年稳定 15% 以上**，就是好公司
- 忽高忽低、断崖下跌，风险偏大

### 一句话记住
> ROE 越高，自家本钱赚钱越猛；长期稳定高 ROE，就是靠谱好生意。
