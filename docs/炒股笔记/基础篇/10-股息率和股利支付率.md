
### 股息率
代表：你买这只股，一年靠分红能拿多少 “年化现金收益”。
```
股息率 = 每股现金分红 ÷ 当前股价 × 100%
```

####  大白话
> 你花 100 块买的股票，一年能拿到多少现金分红。
例：股价 10 元，每股分红 0.5 元 → 股息率 = 0.5 ÷ 10 = 5%。


### 股利支付率
看公司慷慨与否，拿多少钱出来分红。
```
股利支付率 = 每股利支付率 = 每股现金分红 ÷ 每股净利润 × 100%
```
#### 大白话
> 公司每赚 1 块钱，拿出来分给你的比例。
例：每股净利润 1 元，每股分红 0.5 元 → 支付率 = 0.5 ÷ 1 = 50%。


### 思考？为什么说高股息不等于高分红？？

举个极端例子：
某公司：
```text
每股分红：1 元（很低）
股价：10 元 → 股息率 = 10%（很高）
每股净利润：2 元 → 股利支付率 = 50%（中等）
```

另一家公司：
```text
每股分红：3 元（很高）
股价：100 元 → 股息率 = 3%（很低）
每股净利润：4 元 → 股利支付率 = 75%（很高）
```

你看：
```text
第一家股息率 10%，但公司只拿了一半利润分红，分红意愿一般，只是股价便宜显得股息率高；
第二家股息率 3%，但公司拿了 75% 的利润分红，分红意愿很强，只是股价贵，拉低了股息率。
```


所以，和股价的关系极其大！！！

### 怎么选到高股息股？

股息率≥4% + 股利支付率 30%-70% + 连续 5 年分红稳定 / 增长。

原理：
1. 股息率 =	静态 / TTM 股息率	看你现在能拿到多少现金
2. 股利支付率	= 30%-70% 为健康区间	看公司分红意愿强不强，有没有把利润分光
3. 分红连续性 =	近 5 年连续分红，且分红金额稳定或增长	看分红能不能持续，不是一次性表演
