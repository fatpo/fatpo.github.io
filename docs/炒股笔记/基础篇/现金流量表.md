### 经营现金流量净额
一般来说，经营现金流 > 公司净利润，可以认为这家公司赚到了真金白银。

假如一家公司的净利润很高，但是经营现金流很低，证明这家公司有问题：
    
    * 比如说这家公司竞争压力很大，需要不断再投入研发，对产线不断迭代，才能保持竞争力
    * 比如说回款很难，赚的都是欠条？


### 投资现金流量净额

公司投资活动中，产生的现金流。

对外投资是负的。

收回投资是正的。

现在上市公司基本上都会对外投资，不过投资水平一言难尽。 公司把钱投到哪里去？ 是一个比较值得关注的信号。

### 筹资现金流量净额

公司从市场拿钱，比如增发股份、融资、发债、借钱。

公司有现金流流入，就是正的。

反过来就是负的，比如给股东分红，偿还债务等。


### 思考下，最佳的三个现金流数据最理想的组合

经营现金流 > 0 (说明公司赚到钱了) 
投资现金流 < 0 （说明公司赚到钱后有闲钱了，拿一部分钱去投资了） 
筹资现金流 < 0 （说明公司有钱了，不用从市场拿钱，给股东分红）
