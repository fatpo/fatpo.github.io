
### 公式
```
市盈率 = 市值 ÷ 净利润
```

### 直白意思
PE = 19，意思是按现在赚钱速度，**19 年利润能买下整个公司**。

> TTM = 过去 12 个月真实净利润。

### A 股通用好坏标准

| PE | 评级 |
|----|------|
| ＜10 倍 | 超低估值，偏低估、偏安全 |
| 10～20 倍 | 合理健康区间 |
| 20～30 倍 | 中等偏高，偏贵 |
| ＞30 倍 | 高估值，泡沫偏大 |
| ＞50 倍 | 很贵，风险高 |

### 不同行业标准完全不同

| 行业 | 正常 PE 范围 |
|------|-------------|
| 银行、地产、煤炭 | 5-15 倍 |
| 消费、家电、医药 | 15-25 倍 |
| 科技、新能源 | 25-40 倍 |
