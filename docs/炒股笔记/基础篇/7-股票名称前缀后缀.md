
### 前缀

| 前缀 | 含义 | 风险要点 |
|------|------|---------|
| N | 新股首日 | 无涨跌幅，波动大 |
| C | 新股 2-5 日 | 仍无涨跌幅 |
| ST | 特别处理 | ±5%，风险高 |
| \*ST | 退市预警 | 极高危，慎碰 |
| XD | 除息 | 分钱，股价下调 |
| XR | 除权 | 送股，股价下调 |
| DR | 除权除息 | 又分钱又送股 |

### 后缀

| 后缀 | 含义 | 常见市场 |
|------|------|---------|
| -U | 未盈利 | 科创板、港股 |
| -W | 同股不同权 | 港股、科创板 |
| -V | VIE 架构 | 港股 |
