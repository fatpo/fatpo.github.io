
### 推荐选股条件（巴菲特风格）

```
A股 且 非ST 且 非退市股
且 连续5年(2020-2024)净资产收益率ROE(加权)≥10%
且 销售毛利率≥20%
且 经营活动现金流净额>0
且 资产负债率≤70%
且 市盈率(TTM)≤35
且 市净率≤5
且 总市值≥50亿
```

### 如何使用
1. 打开东方财富 APP
2. 进入「选股」或「AI 选股」功能
3. 按上述条件逐个添加筛选指标
4. 按 ROE 降序排列，优先看盈利能力最强的标的

### 筛选条件底层逻辑

| 条件 | 目的 |
|------|------|
| A股 + 非ST + 非退市 | 守住本金安全底线，排除暴雷标的 |
| 连续5年 ROE≥10% | 筛选长期盈利稳定、有护城河的公司 |
| 毛利率≥20% | 剔除低毛利行业，筛选有定价权的公司 |
| 经营现金流>0 | 剔除账面盈利但没现金的公司 |
| 资产负债率≤70% | 控制财务风险 |
| PE≤35 | 避免追高泡沫 |
| PB≤5 | 防止股价严重脱离净资产 |
| 市值≥50亿 | 确保流动性 |
