
### 筛选条件

```
A股 且 非ST 且 非退市股
且 连续5年(2020-2024)净资产收益率ROE(加权) ≥ 10%
且 销售毛利率 ≥ 20%
且 经营活动现金流净额 > 0
且 资产负债率 ≤ 70%
且 市盈率(TTM) ≤ 35
且 市净率 ≤ 5
且 总市值 ≥ 50亿
按 ROE 降序排列
```

### 各条件底层逻辑

| 条件 | 筛选目的 |
|------|---------|
| **A股 + 非ST + 非退市** | 剔除财务造假、濒临退市标的，守住本金安全底线 |
| **连续5年 ROE≥10%** | 筛选长期盈利稳定、有护城河的公司。10% 是 A 股优质公司及格线 |
| **毛利率≥20%** | 剔除低毛利行业，筛选有定价权、品牌壁垒的公司 |
| **经营现金流>0** | 剔除账面盈利但没现金的公司，验证盈利真实性 |
| **资产负债率≤70%** | 控制财务风险，防止被债务拖垮 |
| **PE≤35** | 避免追高泡沫，安全边际原则 |
| **PB≤5** | 防止股价严重脱离净资产 |
| **市值≥50亿** | 确保流动性，避免买不进卖不出 |
