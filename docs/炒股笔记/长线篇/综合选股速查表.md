
### 基本面速查

| 指标 | 合格线 | 优秀线 |
|------|--------|--------|
| ROE（连续5年） | ≥10% | ≥15% |
| 毛利率 | ≥20% | ≥30% |
| 经营现金流 | ＞0 | 持续增长 |
| 资产负债率 | ≤70% | ≤50% |
| PE(TTM) | ≤35 | 10~20 |
| PB | ≤5 | ≤3 |
| 市值 | ≥50亿 | 150~350亿 |
