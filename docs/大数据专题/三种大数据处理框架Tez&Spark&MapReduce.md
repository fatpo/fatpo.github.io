## 1. 背景

Apache Tez、Apache Spark 和 Apache Hadoop MapReduce 是三种不同的大数据处理框架，它们用于处理和分析大规模数据集。以下是对这三种框架的详细介绍：

## 2. Apache Tez

### 2.1. 概述

Apache Tez 是一个用于大规模数据处理的框架，旨在提供更高效的任务调度和更灵活的数据流控制。

它被设计为 `Hadoop MapReduce 的替代品`，通过优化` DAG（有向无环图）`来提高性能。

### 2.2. 主要特点

* 高效的任务调度：Tez 允许复杂的任务调度和优化，减少了任务启动和初始化的开销。
* 灵活的数据流控制：支持复杂的数据流模式，不仅限于 MapReduce 的两个阶段。
* 兼容性：Tez 被用于优化 Hive 和 Pig 的执行引擎，以提高查询性能。

### 2.3. 使用场景

* Hive：Hive on Tez 使用 Tez 作为底层执行引擎，提高 SQL 查询的性能。
* Pig：Pig on Tez 使用 Tez 作为底层执行引擎，提高数据处理脚本的性能。

## 3. Apache Spark

### 3.1. 概述

Apache Spark 是一个快速的通用大数据处理引擎，提供丰富的 API 用于大规模数据处理，包括 `SQL 查询`、`流处理`、机器学习和图计算。

### 3.2. 主要特点

* 内存计算：Spark 主要在`内存中`处理数据，减少了磁盘 I/O，极大地提高了处理速度。
* 统一引擎：支持多种数据处理任务，如`批处理、流处理、机器学习和图计算`。
* 易用性：提供了丰富的 API 支持 Java、Scala、Python 和 R，方便开发人员使用。

### 3.3. 使用场景

* 批处理：使用 Spark Core 进行大规模数据的批处理。
* 流处理：使用 Spark Streaming 进行实时数据处理。
* SQL 查询：使用 Spark SQL 进行结构化数据查询。 （所以我一直用Spark SQL在查数据...）
* 机器学习：使用 MLlib 进行机器学习模型的训练和预测。
* 图计算：使用 GraphX 进行图数据处理。

## 4. Apache Hadoop MapReduce

### 4.1. 概述

Apache Hadoop MapReduce 是一种基于分布式计算的编程模型，用于处理大规模数据集。

它是 Hadoop 生态系统的核心组件之一。

`Ps: 太老了，太死板了，每次中间环节都只能先存I/O再读I/O，导致性能被秒杀。`

### 4.2. 主要特点

* 简单的编程模型：基于 Map 和 Reduce 两个阶段，`简单易理解`。
* 高度容错：通过数据复制和任务重试机制，确保数据处理的可靠性。
* 扩展性：能够处理 PB 级别的数据，适用于大规模数据处理。

### 4.3. 使用场景

* 数据批处理：适用于处理大规模批处理任务，如日志分析、数据转换和索引构建。
* 传统数据处理：适用于传统的大数据处理任务，尤其是需要线性可扩展性的任务。

## 5. 总结

* Apache Tez：主要用于替代 Hadoop MapReduce 提供更高效的任务调度和灵活的数据流控制，常用于 Hive 和 Pig 的执行引擎。
* Apache Spark：一个通用的快速大数据处理引擎，支持批处理、流处理、SQL 查询、机器学习和图计算，适用于各种数据处理任务。
* Apache Hadoop MapReduce：一个基于分布式计算的编程模型，适用于大规模批处理任务，具有高度容错性和扩展性。

每种框架都有其独特的优势和适用场景，选择哪种框架取决于具体的数据处理需求和工作负载。
